# TakeOff UP

Plataforma web para que los alumnos consulten actividades
universitarias relacionadas con sus competencias y registren
sus avances mediante evidencias.

## Funciones principales

- Consultar las ocho competencias universitarias.
- Explorar las actividades disponibles.
- Inscribirse a actividades.
- Subir y descargar evidencias.
- Consultar el porcentaje de avance y las insignias obtenidas.

El progreso aumenta al entregar una evidencia, no al inscribirse
a una actividad.

## Competencias

- Flexibilidad.
- Liderazgo con sentido social.
- Innovación.
- Madurez emocional.
- Compromiso con la verdad.
- Sentido trascendente.
- Excelencia humana.
- Pensamiento crítico.

## Tecnologías utilizadas

- HTML: estructura y contenido de las páginas.
- CSS: colores, distribución y presentación visual.
- JavaScript: interacción y actualización de la información.
- Node.js y Express: funcionamiento del servidor.
- Google Sheets: fuente de las actividades universitarias.
- Git y GitHub: control de versiones y almacenamiento del código.

## Archivos principales

- bienvenida.html: página principal de la plataforma.
- style.css: estilos compartidos.
- script.js: interacción de las competencias y actividades.
- servidor.js: servidor y consulta de datos.
- perfil.html: estructura del perfil académico.
- perfil.css: presentación del perfil académico.

Cada competencia cuenta también con sus archivos HTML y CSS.

## Evidencias

- El tamaño máximo permitido por archivo es de 10 MB.
- El alumno debe inscribirse antes de entregar una evidencia.
- La entrega de evidencias actualiza el avance de la competencia.
